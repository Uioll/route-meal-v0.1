# 顺路去哪吃 V0.1

这是“顺路去哪吃”微信小程序的第一阶段 Python 命令行原型。

本版本使用模拟餐厅与模拟绕路时间，验证以下闭环：

1. 解析“今天想吃什么”；
2. 按预算、菜系、口味、一人食和最多绕路时间筛选；
3. 随机抽取 A、B 两家餐厅；
4. 拒绝后当天不再出现；
5. 选择餐厅后生成模拟三点路线；
6. 保存个人用餐记录。

## 当前限制

- 餐厅、评分、价格和绕路时间均为模拟数据；
- 自然语言解析目前是规则匹配，不是真正的大模型；
- 尚未接入地图、微信小程序、实时营业状态、菜单或团购数据；
- 用餐记录保存在本机 `data/visit_history.json`。

## 下一版本

V0.2 将把核心逻辑包装成 FastAPI 接口，为微信小程序前端调用做准备。
